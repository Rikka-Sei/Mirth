## 1. 背景与目标

### 1.0 设计图景

```text
用户选择登录、注册或重置密码
|-- 输入 homeserver -> 发现服务端身份与可用认证能力
|   |-- 发现成功 -> 展示可用流程，用户选择
|   +-- 失败 -> 显示发现错误；重试回到发现，取消返回入口
|-- 用户提交登录或注册
|   |-- 服务端返回该身份的有效会话且凭据保存完成 -> 建立该账户会话并交给同步服务启动
|   |   |-- 同步启动 -> 显示账户与同步状态；本次认证结束
|   |   +-- 同步不可用 -> 保留已认证账户并显示离线/重试；认证已结束
|   |-- 注册成功但未提供登录会话 -> 显示注册完成并返回登录；不伪造已登录
|   +-- 拒绝、限流、取消或凭据保存失败 -> 不建立已登录状态，保留原因；可重试或返回
+-- 用户按服务端提供的密码重置流程提交
    |-- 重置确认 -> 显示密码重置结果并返回登录；不据此建立会话
    +-- 失败或取消 -> 显示原因或返回入口；不改变本地登录状态
|
用户打开已配置账户
|-- 本地凭据可读且刷新/校验成功 -> 会话服务提供该账户身份给同步服务
|   +-- 同步成功或离线缓存可读 -> 展示账户状态；本次恢复结束
|-- 网络/存储暂不可用 -> 保留账户数据，显示不可用与重试；不推断令牌失效
|-- 服务端要求重新认证且 soft_logout=true -> 停止需认证的操作，保留可复用会话；刷新或按原设备重新认证，取消则停留提示
+-- 服务端确认会话已销毁（soft_logout=false 或缺省） -> 停止旧会话操作，丢弃不可复用的旧设备/加密会话状态；返回登录，新会话不继承旧设备状态

用户切换账户或退出登录
|-- 切换账户 -> 暂停旧账户新操作，保存其会话状态，再恢复所选账户；失败回到可选账户列表
+-- 退出并清除所选本地数据 -> 展示影响与确认
    |-- 用户确认且退出完成 -> 清除所选范围内凭据/数据并返回入口
    +-- 用户取消或退出失败 -> 不声称清除成功；保留可恢复数据并显示原因

用户查看设备并改名、移除设备或跳转账户设备管理
|-- 设备列表可读 -> 展示设备及名称；名称不代表可信
|   |-- 改名/移除经服务端或账户管理确认 -> 更新对应设备状态
|   +-- 请求失败或外部管理未确认 -> 保持最后确认状态，显示失败；可重试或返回
+-- 用户取消 -> 不改变设备状态；本次操作结束

用户发起或响应设备验证
|-- 双方完成适用验证且密码学结果确认 -> 更新相应设备/身份信任，通知加密服务
+-- 比对失败、请求过期、材料不可用或任一方取消 -> 保持未验证，显示原因；可重新发起或结束

用户备份、恢复、导入或导出密钥
|-- 创建/更新备份或导出 -> 用户明确选择范围并完成本地保护确认
|   |-- 保护与保存成功 -> 显示已保存材料及范围
|   +-- 失败或取消 -> 不覆盖既有可用密钥，保留原状态并显示原因
|-- 恢复/导入 -> 检查用户提供的恢复凭据/材料并验证目标
|   |-- 验证成功 -> 安全存储接管材料；向消息解密流程提供可用性变化
|   +-- 错误、拒绝或材料缺失 -> 保留原密钥状态并区分错误；可重试或退出
+-- 无法恢复且用户考虑重置 -> 告知旧密钥保护内容不会因此解密
    |-- 用户明确确认重置 -> 建立新的密钥状态并显示历史解密限制
    +-- 用户取消 -> 不改变密钥状态，返回安全面板
```

本图各步骤是待核验的产品目标，不声明已确认 API 路径。

### 1.1 背景

身份认证、账户会话、设备信任和加密密钥材料彼此相关但有不同所有者。认证成功不能推出设备可信或历史密钥已恢复。来源调查列出注册、密码重置、设备、交叉签名、备份与导入导出等 Cinny 基线操作，不能以精简为由删除。

### 1.2 目标

- D01：保留调查所列认证、设备与密钥维护功能下限；功能可用性由服务端能力决定。
- D02：身份/凭据与密钥状态归本域；会话身份交给其他域，不转移发送事务所有权。
- D03：具体协议映射与操作前置条件尚未核验，均为作者提案。

### 1.3 非目标

- 本域不拥有消息发送、事务身份、重试、取消或发送结果合并；参见[消息发送](../message-delivery/spec.md)。
- 本域不定义加密算法或 homeserver API 签名，不伪造 SDK code facts。
- Demo 或静态设备/密钥数据不构成实现证据。

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 账户会话 | 经认证的账户身份及其可恢复客户端会话，不等同设备信任 |
| 设备验证 | 验证设备/身份并产生信任变化的流程，不是登录认证 |
| 密钥恢复 | 取得既有加密密钥材料并验证可用性的流程，不保证所有历史内容可解密 |
| 软退出 | 服务端令牌错误明确携带 soft_logout=true，允许复用本地会话重新认证；false 或缺省时是会话销毁，不得复用旧设备/加密状态。依据：[Matrix 软退出](https://spec.matrix.org/v1.19/client-server-api/#soft-logout) |
| 重置 | 创建新密钥状态；不恢复旧密钥保护内容 |

## 3. 系统模型与状态机

### 3.1 架构与边界

```text
认证/设备/安全界面 --意图与结果--> 会话与安全协调器
       |                                  |--凭据/密钥存储--> 受保护本地存储
       |                                  |--认证、设备、加密请求--> 协议适配边界 --> homeserver/SDK
       |                                  +--账户身份/信任/密钥可用性--> conversation-ui、rooms-spaces
       +<--状态、失败原因、下一步入口-------------------------------+
```

组件责任：

| 组件 | 输入 | 意图/责任 | 状态所有者 | 失败与接收方 |
|---|---|---|---|---|
| 认证入口 | homeserver、用户选择与认证输入 | 发现、登录、注册、重置密码 | 会话协调器持有流程；存储持有已保存秘密 | 错误/取消反馈入口，不建立假会话 |
| 会话协调器 | 凭据状态、刷新结果、账户选择 | 恢复、切换、软退出、退出 | 当前账户会话 | 同步服务接收身份或失败状态；不处理发送项 |
| 设备面板 | 设备列表、用户设备意图 | 改名、移除、管理跳转 | 服务端确认设备资料 | 确认状态回 UI；失败不伪造移除 |
| 验证流程 | 请求、双方确认、设备/密钥能力 | 验证并请求信任更新 | 加密/信任服务 | 时间线接收可信度变化；失败保持未验证 |
| 密钥流程 | 备份/恢复材料、用户确认 | 备份、恢复、导入导出、重置 | 安全存储/加密服务 | 解密流程接收密钥可用性；失败不覆盖原材料 |
| 协议适配边界 | 目标意图与身份上下文 | 将目标操作映射到已核验 SDK/API | 不持有 UI 状态 | 原始失败映射待核验，返回对应流程 |

### 3.2 状态定义

概念状态包括未认证、认证进行中、已认证、待重新认证、退出中；设备验证未完成/已确认；密钥不可用/可用/备份待确认。它们是图示概念，不是可执行事件模型。

### 3.3 转换与可执行语义

本域没有有限事件模型。具体协议与操作的可执行语义待具体协议抽象及证据调查后定义；不新增 Haskell 模型凑形式，不声称 G7 通过。以上图中的成功、失败、取消均须由未来抽象保持同一后继。

### 3.4 外部输入域矩阵

| 输入 | 成功 | 失败/取消 | 接收方 |
|---|---|---|---|
| 服务发现完成 | 仅展示服务器与认证流程，不建立会话 | 发现失败可重试/返回 | 认证入口 |
| 登录/带会话的注册且凭据保存完成 | 建立该身份账户，交同步服务启动 | 拒绝/保存失败/取消不建立会话 | 会话协调器 |
| 注册未给会话或密码重置确认 | 显示结果并返回登录 | 失败/取消保留原登录状态 | 认证入口 |
| 凭据可读且刷新/校验完成 | 恢复该账户会话 | 临时网络/存储不可用保留数据并重试，不推断失效 | 会话协调器/应用壳 |
| 服务端失效事实且 soft_logout=true | 仅在重新认证完成后恢复可复用会话 | 取消则停止在线操作并保留可复用状态 | 会话协调器 |
| 服务端确认销毁会话且 soft_logout=false 或缺省 | 停止旧操作并丢弃不可复用设备/加密会话状态，转登录 | 新认证失败仍不得复用旧状态 | 会话协调器/安全存储 |
| 设备管理响应 | 更新确认设备状态 | 保持旧状态 | 设备面板 |
| 验证结果 | 更新可信状态 | 保持未验证 | 加密/消息展示 |
| 密钥操作结果 | 安全存储确认后更新可用性 | 不覆盖既有状态 | 解密流程 |

## 4. 功能需求与接口契约

接口签名及具体 API 均未核验；不将以下目标契约当代码事实。

- **REQ-001 认证与账户会话（P0，D01/D03）**：作为账户用户，我需要区分登录、注册和密码重置，以免误以为重置成功已获得会话。Given 服务端提供流程，When 用户完成登录或取得带有效会话的注册结果且凭据保存完成，Then 只建立该身份账户并向同步交付身份；Given 注册未给会话或密码重置确认，Then 返回登录、不标记已认证；Given 拒绝、取消或保存失败，Then 不显示已认证并可重试/返回。
- **REQ-002 账户恢复与切换（P0，D02/D04）**：作为切换或恢复账户的用户，我需要身份隔离且不丢失可复用会话，以免数据串号。Given 网络或存储暂不可用，When 恢复失败，Then 保留数据并允许重试，不推断会话销毁；Given 服务端令牌失效，When soft_logout=true，Then 保留可复用会话并重新认证；When false 或缺省，Then 停止并丢弃旧设备/加密会话状态，不作为新会话继续使用。切换不串用账户；会话服务不创建或重试消息事务。
- **REQ-003 设备与密钥维护（P0，D01/D03）**：作为维护加密账户的用户，我需要独立确认设备信任与密钥恢复结果，以免把登录当成解密成功。Given 设备、验证或密钥操作可用，When 用户管理设备、完成验证、备份/恢复/导入导出或明确重置，Then 仅确认结果更新相应状态；Given 失败/取消/材料错误，Then 不伪造可信、不覆盖既有密钥，并保留恢复路径。

## 5. 错误模型

目标错误类别，不是已核验协议错误码：发现不可用、认证拒绝/限流、凭据存储失败、刷新失效、设备操作未确认、验证失败/过期、恢复材料错误、存储不可用、用户取消。每类保留最后确认状态并将可操作原因交回发起组件；未知错误映射待核验，不能编造 code。

## 6. 非功能需求（NFR）

不设置无依据的性能或容量阈值。秘密不得作为普通视图状态或日志内容；本地数据清理不得与可回收缓存策略混用。存储保护与威胁边界需在实现前由具体协议/平台调查补足，尚未验证。

## 7. 异常与边界条件

| 场景 | 目标结果 |
|---|---|
| 账户切换时旧请求返回 | 不改变新账户的会话、信任或密钥状态 |
| 设备改名成功但验证未完成 | 仅名称更新，不推导为可信 |
| 恢复材料错误 | 不覆盖现存密钥，不标记恢复成功 |
| 重置被取消 | 不改变密钥状态 |
| 软退出 / 会话销毁 | true 保留可复用状态；false 或缺省不复用旧设备/加密状态；网络错误不推断任一结论 |

## 8. 验收标准

- 认证、注册、密码重置的成功/拒绝/取消/存储失败分别满足图；真实服务端策略与流程待核验。
- 设备改名/移除、验证、密钥备份恢复导入导出与重置各有确认和失败证据；不得用 Demo 作为证据。
- 身份服务仅向调用方提供账户/会话结果，不拥有或复制发送事务及待发送项。
- 本域保持 Draft，直至 API 映射、协议语义和实现证据独立核验；本文件不声称 authoritative。
