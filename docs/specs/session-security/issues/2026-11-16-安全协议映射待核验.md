# 认证、设备与密钥协议映射待核验 — Issue

**状态:** open
**发现日期:** 2026-11-16
**最后更新:** 2026-11-16
**来源:** 规格拆分与调查报告
**关联章节:** [spec §1](../spec.md#1-背景与目标)、[REQ-001–003](../spec.md#4-功能需求与接口契约)
**关联决策 ID:** 未归因

## 1. 现象

目标规格保留 homeserver 发现、登录/注册/密码重置、会话恢复、设备管理/验证及密钥备份恢复/导入导出，但具体协议/API 调用、失败映射及操作可用条件尚未核验。

## 2. 证据链

| 证据 | 位置 |
|---|---|
| 调查报告列出认证、设备、交叉签名、SSSS、备份及导入导出能力，同时指出需进一步核对流程 | [调查报告](../../../research/客户端核心规格调查.md) §§能力表与 Cinny 源码调查 |
| 领域规格明确签名和 API 未核验，不声明代码事实 | [spec §4、§10](../spec.md) |

## 3. 根因

拆分来源提供能力线索及局部源码调查结论，不等于本次已逐个核验协议交互与 SDK 版本。

## 4. 影响

规格只能定义产品目标，不能据此直接编写声称已有的 API 签名、错误码或完整恢复保证；当前状态保持 Draft。

## 5. 建议

实施前按受支持的服务端/SDK 能力逐项调查认证、设备与密钥操作，将真实签名及失败映射以证据闭环；需求范围不得因此删减。

## 6. 闭环记录

- open：等待具体协议与 SDK 版本证据及 §9 决策归因。
