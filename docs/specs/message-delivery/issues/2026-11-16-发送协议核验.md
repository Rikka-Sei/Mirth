**状态:** open

**最后更新:** 2026-11-16
**来源:** 聚合稿拆分及旧代模型边界核对
**关联章节:** §1.0、§3、§4、§7、§10
**关联决策 ID:** D03（仅归因模型边界，不代表问题解决）

## 1. 现象

嵌入模型只有阶段、活动位与抽象观察，没有事务/事件/快照实体；真实 Matrix 提交、上传、加密、去重与恢复还没有实现。不能由有限表的性质 PASS 推断内容、事务身份或网络发送正确。

## 2. 证据链

- `../spec.md` §3.2 明示 legacy/unverified；代码块只投影一次本地尝试。
- `src/model.ts` 仅向当前页面添加“仅本地”示例消息，没有 SDK 传输/同步链路。
- `tests/model.test.ts` 验证本地草稿数据归属，不覆盖服务端确认、未知结果与稳定事务身份。

## 3. 根因

本次交付是产品规格 Draft 与已确认的本地 UI Demo，不是完整协议客户端实现。SDK 版本与服务端矩阵未冻结。

## 4. 影响

G4 的产品屏障、G8 的真实实现一致性未满足；旧代共享语义工具应报告 UNVERIFIED，不能宣布 authoritative 或 strict pass。

## 5. 建议

按选定 SDK 的真实 API 与同步事实核验未知结果、事务复用、加密/上传失败、取消后远端晚到及恢复不覆盖新输入。证据推翻目标图时先修改图与决策，不能修改测试输入冒充正确。
