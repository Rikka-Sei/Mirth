# issues/ 使用规则

本目录登记 web-platform 规格生命周期中尚未由 §9 决策闭环的问题与风险。issue 是调查记录，不是规范性正文；行为以 `spec.md` 与其 §9 为唯一权威。

## 目录规则

- 一个问题/风险一个文件，命名 `YYYY-MM-DD-<中文短slug>.md`，日期为首次登记日。
- 状态原地流转：`open` → `resolved` / `wontfix`；结束状态必须填写 `spec.md` §9 中的决策 ID。
- issue 只供定位，不替代规格条款；无关变更不得修改状态。

## 文件骨架

新问题使用以下字段：标题；状态/发现日期/最后更新/来源；关联章节与决策 ID；现象；证据链；待确认根因；影响；建议；闭环记录。`resolved` 或 `wontfix` 必须填写 §9 决策 ID 与对应结果。
