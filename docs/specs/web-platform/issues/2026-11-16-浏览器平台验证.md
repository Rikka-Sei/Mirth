## 3. 根因

目前没有指定浏览器、真实 Matrix 推送网关、多标签目标或测试输出；具体平台兼容性待测，不推断为已知产品缺陷。

## 4. 影响

配额边界、数据保留与多标签正确性仍是目标契约；不能把表中数字宣传为产品容量，也不能以静态 Demo 宣称推送/PWA 已实现。

## 5. 建议

在目标浏览器/网关上取得配额压力、并发交接、权限撤销、推送注册及更新失败路径证据；数值须经用户批准后方可成为验收预算。完成前保持 open。
