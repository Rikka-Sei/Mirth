# 原生界面演示实施计划

> 执行方式：当前会话主代理内联实现；CSS 与规格文档独立并行编写，主代理统一集成、检查和提交。

**目标：**交付可点击的桌面/手机聊天 Demo、明确的无框架选型说明及符合 core-spec 目录与设计图规则的产品草案。

**架构：**原生 DOM 组件组合，TypeScript 本地状态，Vite 构建；示例数据与 UI 分离。Demo 不连接 Matrix；正式协议路线为 matrix-js-sdk。原生 dialog 负责临时模态焦点与退出，不引入 UI 框架。

**技术：**pnpm、TypeScript、Vite、原生 CSS、Node 内置测试；无需生产 UI 依赖。

**Spec：**`docs/research/技术选型与界面设计.md` 记录 Demo 边界；`docs/specs/README.md` 导航六个目标产品 Draft，不把其全部要求声称已实现。

## 全局约束与执行裁定

- 用户“推进直到结束”授权继续选型—Demo—规格交付，不重复询问已定方向。
- 使用现有工作区便于用户直接查看，避免另建 worktree 导致并行文件与 Demo 不在用户当前目录；只提交本会话归属修改。
- 无假登录、假加密、假远端送达。界面常驻“交互演示/示例数据”说明，消息标记“仅本地”。
- 产品 Cinny 功能下限不缩减；本次 Demo 是已确认的可视交付，不是功能齐全的 Matrix 客户端。
- UI 演示不安装不使用的 SDK、编辑器或组件库。版本由 pnpm 锁文件固定。
- 构建后用真实浏览器操作验证，不把静态引用检查当作界面证明。

## 文件与共享契约

- `index.html`：可访问的应用壳与 dialog、常驻演示说明。
- `src/data.ts`：固定示例房间、消息、成员；无真实用户资料。
- `src/model.ts`：按会话隔离草稿、回复、附件；筛选和本地发送。
- `src/dom.ts`：文本安全的 DOM 和静态 SVG 图标工具。
- `src/main.ts`：导航、列表、时间线、编辑器、搜索、详情、设置事件组合。
- `src/style.css`：主题/密度令牌、网格、消息与响应式；由样式代理独占。
- `tests/model.test.ts`：用户可感知的房间上下文隔离、空消息和本地发送边界。
- `package.json`、`tsconfig.json`、`pnpm-lock.yaml`：可复现开发、类型检查、构建与测试。
- `docs/specs/`：按账户与安全、房间与空间、会话交互、消息发送、通话、Web 平台六域分配规格与自包含工具；主代理维护跨域责任，编写代理不交叉改文件。
- `README.md`：启动方法、可操作项目与明确未接入内容。

## 检查重点

1. 在 A 房间回复/选附件后切到 B，不得发错房间，空消息不得清除草稿上下文。
2. 用户输入与文件名作为文本，不注入 HTML；输入法组合中 Enter 不发送。
3. 缩小窗口、打开/关闭详情与浏览器返回，不丢当前会话草稿或让后台视图可聚焦。
4. 本地图片对象 URL 在取消、页面结束时回收；容量有上限，错误直接可见。
5. 发送、反应、设置、筛选均有真实本地效果；未接入的通话/验证不伪造可用按钮。
