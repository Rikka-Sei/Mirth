## 真实浏览器检查

使用工具提供的自有 headless 浏览器，通过实际 DOM 控件操作，不修改应用内部状态伪造结果。

### 桌面 1440×900

- 从设计房间输入草稿后切到 Lin，私聊输入为空；在私聊添加本地消息后返回，原设计草稿恢复。
- 消息正文 `<img src=x onerror=alert(1)>` 作为文字显示，没有创建图片元素。
- 回复 Lin 的示例消息显示引用；取消引用不清空正文。
- 当前会话搜索“手机”得到 2 条示例消息；列表搜索 ` LIN ` 匹配 Lin；私聊筛选为 3 个会话。
- 打开详情查看文件，再切成员；关闭按钮与 Escape 可关闭。
- 开启详情时为非模态附加区域，不阻断桌面主会话。
- 页面未出现横向溢出。

### 手机 390×844

- 默认只显示会话列表；选择会话后显示聊天并隐藏列表。
- 详情使用真实原生模态 dialog；关闭详情、返回列表、重进会话后草稿仍保留。
- 外观设置可切换深色/浅色和舒适/紧凑。
- 实际选择本地文本附件，可取消；取消后无正文和附件时发送按钮不可用。
- 纯附件可加入本地消息并出现本地保存入口，消息标记“仅本地”。
- 使用本次浏览器生成的 WebP 截图作为真实附件，检查图片 `complete` 且 `naturalWidth > 0`，预览可解码；没有上传。
- 手机 Ctrl+K 原先把焦点留在隐藏编辑器。修复为路由完成、列表解除 inert 后再聚焦；再次实际按键检查，焦点进入 `room-search`。

### 静态生产构建与 320×740 边界

- 通过 `pnpm preview --port 4173 --strictPort` 访问 `dist/`，不是只验证开发服务器。
- 生产构建检查八个会话、成员详情、Escape、主题密度及本地消息添加均通过，采集时浏览器错误列表为空。

### 独立审阅后的回归

- 可访问性审阅发现：缩到手机后没有空间筛选入口；密度变量未作用到实际消息元素。已新增手机空间选择，并将间距应用到时间线实际布局。
- 行为审阅发现：浏览器历史返回列表时，窄屏模态详情未关闭。已在路由切换为列表时关闭详情。
- 实际检查手机从 Mirth 空间的 3 个会话切回全部 8 个、浏览器后退关闭详情、舒适密度的实际 rowGap 大于紧凑密度，均通过。
- 修复后再次运行 3 项模型测试、类型检查与静态构建通过；重新加载最新静态产物后，320 CSS px 下空间切换、历史返回及无横向溢出通过，浏览器错误列表为空。
- 将同一生产页面缩到 320×740：当前会话可保留、详情变为模态、可以返回列表；文档宽度不超过视口。
- 六域规格拆分后重新打开同一 `dist/` 预览：1440×900 桌面详情与390×844聊天均实际截图，两个标签页错误列表均为空；本轮没有改动 Demo 代码。

- HMR 编辑期间出现过中断的旧模块请求；这不是生产构建运行结果。生产预览另行检查，无错误记录。
- 未进行长时间内存观测、网络弱网测试或与 Cinny 同条件基准，不声称性能达标。
- 规格工具、内嵌语义与独立审阅结果在各自完成后补充，不把本记录当成核心规格通过证明。
