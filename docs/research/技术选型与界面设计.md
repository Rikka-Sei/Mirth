# 技术选型与界面设计

**状态：** Draft；这是选型说明，不是产品规格或 Matrix 兼容性证明。
**关联：** [六域规格入口](../specs/README.md)，均为 Draft；协议、平台和安全开放问题分别放在各域 `issues/`。

## 目标与约束

客户端要小巧、响应式、多端一致，尽量不引入框架；Matrix 协议复用 `matrix-js-sdk`，不自建协议栈。先交付可明确说明范围的本地 Demo，UI 展示真实交互状态，不用示例数据伪装服务端事实。已批准发送路径及其他用户操作的目标结果以 core spec 为准。

## 选型权衡

| 领域 | 倾向选择 | 收益 | 成本与边界 |
|---|---|---|---|
| UI | 原生 DOM 组件函数与浏览器平台 API，不引入 UI 框架 | 无框架运行时，可直接利用标准 DOM/CSS | 必须管理事件、订阅、焦点和资源释放；不为组件化自建通用渲染框架。本 Demo 没有使用 Custom Elements 或 Shadow DOM |
| 语言 | TypeScript | 在浏览器端提供静态检查，便于隔离用户意图、视图状态与协议边界 | 运行时验证仍需处理外部数据；类型不能证明协议数据可信 |
| 样式 | CSS 自定义属性、Grid/Flex、容器/媒体查询 | 响应式布局无需额外布局库，可按窄屏/宽屏调整导航与面板 | 需定义少量设计 token 与焦点/对比度规则；不能只依赖屏幕尺寸推断能力 |
| Matrix | `matrix-js-sdk`，放在独立适配层 | 复用 SDK 的协议和加密相关能力，避免重复实现规范细节 | 版本、浏览器兼容、E2EE/设备恢复/通话能力和 server 差异必须逐项核验；SDK 不替代产品错误语义 |
| 本地状态 | 领域服务拥有账户/房间/草稿状态；视图读取可观察投影 | 布局切换不改变数据归属，Demo 和未来 SDK 可以共用界面契约 | 未来多标签页同步、密钥存储、离线缓存一致性须独立验证 |
| 打包 | pnpm + Vite + TypeScript，锁文件固定版本 | 开发服务、类型检查和静态构建与 UI 运行时分离 | 当前使用 Vite 7.3.8、TypeScript 5.9.3、pnpm 11.27.0；这些是开发依赖，不代表已验证完整产品兼容 |
| PWA | 标准 manifest/service worker 按需加入，浏览器能力明确呈现 | 可安装且可渐进离线 | 安装提示、推送、后台同步在不同浏览器不一致；本次 Demo 不声称离线协议操作可用 |

无框架不是禁止一切工具：构建、类型检查和 Matrix SDK 都是显式依赖；不因“精简”重造 SDK、加密、虚拟列表或路由中的高风险能力。框架是否必要，应按真实复杂度和包体/性能测量复审，而非预先增加抽象层。

## 依赖与边界

```text
原生 DOM / CSS
          ↓ 用户意图与视图投影
应用流程与领域服务 ─── 本地示例数据源（Demo）
          ↓ 未来网络适配接口
matrix-js-sdk ─── Matrix homeserver
```

Demo 与线上适配器共享可观察的应用流程，不共享伪造的 SDK 成功回包。适配器返回明确的成功、失败、取消或未知结果；视图层不得自行将 timeout 解释为服务端拒绝。发送事务身份、去重、取消与账户隔离契约见 core spec。

## Demo 实际范围

当前 Demo 只实现会话/空间筛选、会话与当前消息的本地搜索、房间草稿隔离、引用回复与取消、本地文字/附件消息、反应切换、详情成员/文件及主题/密度。桌面并排列表与会话；手机默认列表，选择后进入会话。消息明确标记“仅本地”。它不演示服务端接受、发送结果待确认、认证、加入、设备验证、密钥恢复、通话或 PWA 安装成功，不将产品目标图冒充已有界面。

Demo 不连接 homeserver，不注册用户，不发送 Matrix 事件，不验证设备或恢复密钥，不加解密真实消息，不采集麦克风/摄像头，不证明推送、后台同步或跨设备一致性。未接入的产品能力在说明中列明，不放置伪成功按钮。正式富文本编辑器需独立验证，Demo 文本输入不代表 Cinny 编辑能力已对齐。

## 设计方向

- 窄屏优先保留当前单一主上下文，房间列表和设置通过独立导航层访问；宽屏可并列房间导航与内容。视口变化不得重置账户、房间、草稿和阅读锚点。
- 时间线与编辑器使用稳定的账户/房间/线程作用域；失败和同步状态贴近受影响对象展示，不用全局 toast 代替持久状态。
- 明确区分未发送、等待网络、结果待确认、服务端已接受；也区分缓存历史、完整性未知及不可见房间。
- 加密/信任界面显示证据来源和当前状态；不得用绿色成功样式表达尚未验证设备。
- 设置分账户与设备两种作用域；保存失败展示上次确认值与未保存状态。
- Demo 使用有名称的按钮、可见焦点、原生模态 dialog、320 CSS px 最小视口和减少动态效果规则。实际验证记录见 [界面演示验证记录](界面演示验证记录.md)；未实测读屏、真实软键盘与操作系统输入法。
