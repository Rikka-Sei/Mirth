# Mirth

面向 Matrix 的网页客户端设计与原生界面演示。界面参考 Telegram Web K 的聊天组织方式，正式产品以 Cinny v4.12.8 为功能下限。

**当前是可点击 UI Demo，不是已接入 Matrix 的客户端。**所有账户、房间、成员和初始消息都是示例数据；不会登录服务器、上传附件或发送消息。

## 本地运行

需要 Node.js 24 及 pnpm 11。仓库 Nix 环境已提供 Node.js、pnpm、Make 与 Python：

```sh
nix develop
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173/`。

```sh
pnpm test       # 会话草稿/附件/引用隔离与本地发送边界
pnpm build      # TypeScript 检查与静态构建
pnpm preview   # 预览 dist/ 构建结果
```

pnpm 仅允许锁定的 `esbuild@0.28.2` 安装脚本，不全局放开依赖脚本。构建结果位于 `dist/`，可作为静态网站预览；开发和预览服务默认只监听本机。

## 可以操作什么

- 桌面空间导航、会话列表与聊天；窄屏默认列表，进入聊天后可返回。
- 全部、私聊、未读和空间筛选；会话搜索及当前会话的本地消息搜索。
- 按会话保留正文、引用与附件草稿；引用回复、取消回复和本地反应切换。
- Enter 添加本地消息，Shift + Enter 换行；输入法组合态不提交。
- 选择/取消本地附件，添加纯附件消息；可预览常见图片及保存所选本地文件。
- 查看会话示例资料、成员与文件；桌面详情为附加列，窄屏为模态侧页。
- 浅色/深色主题、紧凑/舒适密度；Ctrl/⌘ + K 聚焦会话搜索。

## 数据与限制

- 消息、附件、回复、反应和草稿仅保存在当前页面内存；刷新即恢复示例数据，不承诺持久化。
- 主题与密度在浏览器允许时存入本机 `localStorage`，存储被拒绝时仍在本页生效。
- 每条消息最多 4 个附件、单文件最多 5 MB、当前页面附件总量最多 40 MB；每个房间最多添加 100 条本地消息，正文最多 8000 字符。
- “仅本地”不表示已上传、服务端接受、其他设备收到或对方已读。
- 初始示例文件没有真实文件内容；选中的本地文件才有保存入口。
- 未接入登录、Matrix 同步、加密、真实成员/在线状态、富文本、通话、消息持久化、PWA 安装、离线壳及后台推送。不会用假按钮或假成功状态表示这些能力。
- 正式协议与加密路线为 `matrix-js-sdk` 及其加密接口；本 Demo 不安装未使用的 SDK 或编辑器。其最终版本、资源预算与服务端兼容须单独验证。
